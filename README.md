# Google Meet Clone Frontend

A modern Google meet clone built with React, focusing on replicating core  functionalities and user interface of the app.

# Aims of this project

### To learn webrtc on a deeper level
### To learn to use socket.io as a signalling server and also learn more about websockets,i know socket.io is a websocket not is it a wrapper around it.
### To learn testing both on frontend and backend.
### To get intuition writing css as i plan to rewrite all the css once i finish taking joshcomeau's css course ,therefore taking my css skills to another level.
### To improve  my web fullstack development skills.

## Features

- Email composition and sending
- Inbox management
- Email categorization (Primary, Social, Promotions)
- Responsive design
- Material UI components
- Redux state management

## Technologies Used

- React
- Redux Toolkit
- Material UI
- TypeScript
- Socket.IO Client

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn
### Installation

1. Clone the repository:
```bash
git clone <repository-url>
```

2. Navigate to the project directory:
```bash
cd <project folder name>
```
3. Install dependencies:
```bash
yarn install
```
4. Install dependencies:
```bash
yarn start
```
The application will be available at http://localhost:3000
